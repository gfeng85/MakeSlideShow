# 照片幻灯片 Premiere 工程生成器

把任意照片目录（默认 `PIC`）下的照片批量生成一个 **Adobe Premiere Pro 工程文件（.prproj）**：
照片按文件名自然排序进入时间线，每张播放 3~5 秒（可调、随机），叠加随机的轻微缩放 / 左移 / 右移
运动（Ken Burns 效果），相邻照片之间使用随机视频过渡，生成的文件可直接用 **Premiere 2022** 打开。

| Python             | 3.13+，**纯标准库**，无任何第三方依赖                          |

## 快速开始

```bat
:: 1. 把照片放进 PIC 目录（或任意目录），然后运行：
python make_slideshow_prproj.py

:: 2. 结果：当前目录生成 照片幻灯片放映.prproj

:: 3. 用 Premiere 2022 双击打开该文件即可（首次打开需等待媒体缓存）
```

常用变体：

```bat
:: 指定照片目录与输出路径，固定随机种子（保证可复现）
python make_slideshow_prproj.py --pic-dir D:\photos --out D:\out.prproj --seed 42

:: 调整时长与运动幅度
python make_slideshow_prproj.py --min-dur 4 --max-dur 6 --zoom-min 3 --zoom-max 8

:: 按文件名升序排列（默认是随机）
python make_slideshow_prproj.py --order name_asc

:: 按照片创建时间降序（最新在前）
python make_slideshow_prproj.py --order ctime_desc

:: 调试：只处理前 10 张，快速看效果
python make_slideshow_prproj.py --limit 10 --seed 42
```

## 工作原理

### 4.1 .prproj 文件本质

Premiere 工程文件不是二进制私有格式，而是 **gzip 压缩的 XML**：

- 外层：`<PremiereData Version="3">`，根下有 `<Project ... Version="40">`（对应 Premiere 2022）；
- 对象用两套标识：**`ObjectID`**（数字，进程内引用）与 **`ObjectUID`**（GUID，跨文件引用），
  通过 `ObjectRef` / `ObjectURef` 互相引用；
- 整个文件是一个对象图：项目设置 → 素材库（Media / MasterClip / ClipProjectItem）→
  时间线（Sequence / TrackGroup / Track / TrackItem）→ 效果（VideoFilterComponent / 参数）。

生成器以你提供的示例工程 `example\未命名.prproj` 为蓝本，逐对象镜像其结构；
其中不随照片变化的固定段（项目视图状态、编译设置、音频轨、混音台等）提取为
`prproj_templates.py` 中的 6 个常量模板，动态部分由生成器按照片数量现算。

### 4.2 双层轨道结构

每张照片在时间线上占两行（V1、V2 视频轨），共用同一个媒体源：

```
V1 背景轨  [照片A 模糊背景] [照片B 模糊背景] ...
V2 前景轨  [照片A Ken Burns] [照片B Ken Burns] ...
```


| 轨道    | 内容       | 缩放规则                                  | 效果                 |
| --------- | ------------ | ------------------------------------------- | ---------------------- |
| V1 背景 | 同一张照片 | **宽度铺满**序列（`3840/照片宽 × 100%`） | 高斯模糊（默认 300） |
| V2 前景 | 同一张照片 | 横图**满屏铺满**；竖图**高度铺满**        | 随机 Ken Burns 运动  |

**为什么双层**：竖图按高度铺满后，宽度通常不足 4K 画幅，画面两侧会空出来。
垫一层"同照片宽度铺满 + 高斯模糊"的背景后，空出的区域显示为同色系的模糊画面，
而不是黑边——这正是你示例里的设计。运动时照片左右平移露出的部分也由背景兜底。

### 4.3 缩放与运动（Ken Burns）

**基础缩放（铺满基准）**：

```
横图：base = max(3840 / 照片宽, 2160 / 照片高) × 100%   # 满屏铺满
竖图：base = 2160 / 照片高 × 100%                       # 高度铺满
```

**运动规划**（`plan_motion()`，约 1090 行）：每张照片随机抽一种运动类型并生成
缩放/位置关键帧，关键帧以 30fps 序列时间写入"运动"（AE.ADBE Motion）效果：


| 类型       | 权重 | 行为                          |
| ------------ | ------ | ------------------------------- |
| `zoom_in`  | 20%  | 纯放大（base → base+Δ）     |
| `zoom_out` | 15%  | 纯缩小（base+Δ → base）     |
| `pan_l`    | 14%  | 左移（锚点 0.5∓m → 0.5±m） |
| `pan_r`    | 14%  | 右移                          |
| `pan_u`    | 7%   | 上移                          |
| `pan_d`    | 7%   | 下移                          |
| `zoom_pan` | 23%  | 放大或缩小 + 左右移动         |

幅度控制（保持"轻微"）：

- Δ（缩放增量）默认取 2%~6%（`--zoom-min/--zoom-max`），平移类自动提高到 6%~10% 以腾出移动空间；
- **横图**（满屏，无富余画幅）：平移量取缩放余量的 40%~75%，即总移动约 3%~8% 画面，不会露出照片边缘；
- **竖图**（高度铺满、宽度不足）：横向平移只取画面宽度的 2%~4%、纵向取 1.5%~3%
  （刻意调小，避免竖屏大幅晃动破坏观感），移动露出的区域由 V1 模糊背景承接；
- 任何情况下前景缩放不超过 `--max-scale`（默认 110%）。

### 4.4 视频过渡（转场）

相邻照片边界各随机抽一种转场（当前共 **20 种**，权重见[一览表](#转场与运动一览)）。
转场对象挂载在 V2 前景轨的边界上（背景轨不加转场，与示例一致），时长默认 25 帧、
在边界两侧各占一半（可 `--trans-frames` 调整）。

两种工程内实现形式：

1. **无滤镜原生转场**（绝大多数）：`VideoTransitionTrackItem` 直接写 `MatchName`，
   不带效果滤镜——与示例中"中心拆分"同构。参数全走插件默认，零猜测；
2. **带滤镜转场**（交叉溶解、VR 光圈擦除）：额外携带 `VideoFilterComponent`
   及精确参数（含 PrivateData / BinaryHash），结构与示例一致。

> 所有转场的 `MatchName` 均取证自 Premiere 2022 安装目录 `Mezzanine.dll`
> 的转场注册表（`ADBE Dip To Black`、`ADBE Iris Round`、`AE.ADBE Push` 等），
> 不是凭记忆拼写，因此不会出现"脱机转场"。带 `AE.` 前缀但未取证参数结构的
> 转场（Push/Slide/Wipe/Whip）未盲目加入，避免写错参数导致工程拒载。

### 4.5 背景音乐（照片应用配乐，可选）


1. **收集曲目**：默认把 `Audio\` 目录（或照片应用音乐缓存）里的**全部音频**都收进配乐；
   `*_Intro.aac` / `*_Main.aac` 按同名前缀自动配对成一首（前奏→主旋律连续播放），
   单文件（如 `--music` 指定的）按单曲处理；
2. **播放计划**：曲目按文件名自然排序依次播放——每首的 Intro 段 + Main 段顺次铺入时间线，
   **全部播完视频还没结束就从第一首重新循环**，直到覆盖整条时间线；
   段与段之间无缝衔接（与示例"一段音频循环 4 次填满 20s"同构），每段时长 = 该文件完整
   时长（帧对齐），只有视频结尾处的最后一段会被截断；
3. **结尾渐弱**：全局最后一个播放段挂 `Internal Volume Stereo`（音量）+ `Internal Channel Volume Stereo`（通道音量）滤镜，"级别"参数写**片段内时间**的渐弱关键帧：
   基础音量约 -15dB（`0.1778`，与示例一致），在最后 `--fade-sec`（默认 2s）内线性
   衰减到 0；关键帧格式与示例完全相同（`时间,值,0,0,0,斜率…`）。如果视频结尾正好
   落在某首曲子中间（被截断），渐弱就挂在这段截断的片段上；
4. 音乐挂在 **A1 音轨**（4 条音轨的第一条），其余轨留空；每首曲目在素材库中独占
   一套对象（Media/MasterClip/SubClip 等），循环播放同一首时复用素材库、只新增时间线段。

> 配乐总长通常远超视频长度（48 首 ≈ 42 分钟），此时按序播放自然截取前若干首，
> 不会触发循环；只有视频比音乐还长时循环逻辑才会生效。

### 4.6 照片顺序

默认 **随机**（`--order random`，由随机种子驱动、可复现），也可固定排序：


| `--order`    | 行为                                                     |
| -------------- | ---------------------------------------------------------- |
| `random`     | 随机打乱（默认）                                         |
| `name_asc`   | 文件名自然排序升序（`20260204_1.jpg < 20260204_10.jpg`） |
| `name_desc`  | 文件名自然排序降序                                       |
| `ctime_asc`  | 文件创建时间升序（最早的在前）                           |
| `ctime_desc` | 文件创建时间降序（最新的在前）                           |

> 注：`ctime_*` 按操作系统记录的**文件创建时间**排序（Windows 上即文件系统的
> 创建时间），不解析照片 EXIF 拍摄时间。需要 EXIF 排序可以再扩展。

### 4.7 随机与可复现

- 时长、运动、转场、**照片顺序**全部由 `random.Random(seed)` 驱动；
- 不填 `--seed` 时自动取随机种子并打印，填了则**同种子 → 同工程**（便于复现/对比）；
- 每张照片时长按 30fps **取整到帧**（如 3.4s → 102 帧），保证时间线无小数帧。

### 4.8 生成与自我验证流程

```
读图 → 按 --order 排序 → 随机时长/运动/转场 → 按"发射顺序"分配对象编号ID（文件内严格升序）
→ 组装 XML（模板段 + 动态段） → validate() 自检 → gzip 写出 .prproj
```

`validate()` 会解析自身输出并检查：

- XML 语法可解析；
- 生成器自分配段（ObjectID ≥ 1000）无重复；
- 所有 `ObjectRef` / `ObjectURef` 均能解析到目标。

自检通过后还有一道**实测验收**（开发期使用，脚本在
`prproj_study\accept_prproj.py`）：用系统命令启动 Premiere 打开生成的工程，
轮询主窗口标题直到出现 `Adobe Premiere Pro 2022 - <工程路径>` 即判定打开成功。
224 张全量工程实测通过。

## 常见问题

**Q：Premiere 提示"无法加载项目，它可能已损坏或包含过期元素"**

- 确认 Premiere 版本 ≥ 2022（工程为 Project Version=40）；
- 确认工程文件未被文本编辑器等工具"修复"过（gzip+XML 的字节结构必须原样）；
- 如果改动过生成器，重跑一遍再打开。

**Q：照片路径变了（PIC 目录移动/改名）**

- Media 里同时写入了相对路径与**绝对路径**（`ActualMediaFilePath`），
  Premiere 优先按绝对路径取媒体；移动照片目录后重新生成一次即可。

**Q：想统一时长 / 关掉运动 / 只用某几种转场 / 关掉音乐**

- 统一时长：`--min-dur 4 --max-dur 4`；
- 调运动：改 `plan_motion()` 里的 `weights` 与幅度系数；
- 调转场：改 `TRANS_TYPES` 的权重或删掉不想要的键；
- 关音乐：暂时移走 `Audio\` 目录（或改名），生成器检测不到音乐来源就不插音频。

**Q：背景音乐怎么换 / 指定某首歌 / 只放部分曲目**

- 只播一首并循环：`--music "D:\my\song.aac"`；
- 只收某一风格：`--music-style Epic`；只收主旋律段：`--music-track Main`；
- 想在 `Audio\` 目录只放你想用的几首也可以（默认收集全部）；注意同名文件会被
  照片应用缓存来源覆盖复制。要完全不用音乐：暂时移走 `Audio\` 目录。

**Q：转场看起来"单调"或想加推挤/滑动类**

- 推挤（Push）、滑动（Slide）、擦除（Wipe）在 Premiere 中是带滤镜参数的 AE 类转场，
  参数结构未取证前没有写入工程（写错参数会导致拒载）；
  如需加入：在 Premiere 手动添加一次并保存工程，把该 `.prproj` 发来即可提取参数。

**Q：照片数量很多，Premiere 打开慢**

- 首次打开会为每张图建媒体缓存，属正常现象；生成时 `--limit` 可先小规模验证。
